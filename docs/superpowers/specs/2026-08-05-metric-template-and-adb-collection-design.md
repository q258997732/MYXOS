# 指标模板与 ADB 采集设计

## 目标

将统一频率的指标采集改为由模板驱动的按指标调度：主机和安卓实例均可应用多个指标模板，按单项频率采集；安卓实例可覆盖主机继承的配置。引入经过验证的 ADB 指标体系，按指标类型驱动阈值条件，并修复阈值持续时长编辑回显为零的问题。

## 范围

- 管理员维护指标模板、模板指标项、主机绑定和安卓实例绑定。
- 系统内置受控指标目录，命令与解析规则不允许由管理员直接编辑。
- 主机和安卓实例按已应用指标模板中的单项频率采集。
- 安卓实例非运行中时停止实例指标采集；主机非在线或非运行中时停止主机指标采集。
- 指标区分主机与安卓实例，支持数值、字符和枚举三类值。
- 阈值规则按指标名称与指标类型配置条件。
- 指标历史统一按系统配置的保留天数清理，默认 30 天。
- 修复持续时长规则编辑时错误回显为 0 秒。

## 不在范围内

- 不开放任意 ADB Shell 命令作为周期采集模板。
- 不执行会改变目标实例状态的命令。
- 不为每个指标或设备创建独立的定时线程。
- 不改变既有主机和安卓实例生命周期操作语义。

## 核心模型

### 指标目录

`metric_catalog` 是系统受控的指标定义，包含：

- `code`：稳定、唯一的指标编码。
- `name`：指标名称。
- `target_type`：`HOST` 或 `ANDROID_INSTANCE`。
- `value_type`：`NUMBER`、`STRING`、`ENUM`。
- `category`：性能、状态、基础属性、应用等。
- `unit`：数值指标单位。
- `command_key`：内置的只读采集命令与解析器标识，不暴露给管理员编辑。
- `threshold_enabled`：是否可配置阈值。

目录中的 ADB 命令必须先在授权样本实例验证返回格式、解析结果、执行耗时与输出大小。命令返回非零 `shell_code`、超时或解析结果不合理时，不得加入默认模板。

首批安卓指标包括：Android 版本、设备型号、CPU 核心数、CPU 总使用率、CPU 空闲率、内存总量、可用内存、最近应用、前台应用、运行任务数、运行时长等。命令以实际设备响应为准，避免直接采用未验证的管道命令。

### 指标模板

`metric_template` 是管理员可维护的可复用模板；`metric_template_item` 关联受控目录指标，并包含：

- 模板默认采集频率。
- 默认启用状态。
- 枚举指标的 `enum_options` JSON。

枚举指标在验证阶段提取候选值并经确认后写入模板项。例如安卓实例状态可使用 `RUNNING`、`STOPPED`、`UNKNOWN`。阈值配置只能从已应用模板项的枚举选项中选择，不能自由输入。

### 绑定与优先级

`metric_binding` 代表一个模板指标项在目标上的生效配置，支持目标为主机或安卓实例，并包含启用状态和频率覆盖值。

一个主机或安卓实例可以同时应用多个模板。安卓实例的直接绑定优先于同一指标的主机继承绑定；直接绑定可停用继承项或覆盖其频率。最终生效频率为：实例覆盖频率、实例模板默认频率、主机覆盖频率、主机模板默认频率的首个有效值。

## 调度与采集

采集器采用固定短周期扫描到期绑定项的模型，而非为每项创建定时任务：

1. 加载启用且到期的有效绑定项。
2. 先检查主机在线/运行状态或安卓实例运行状态；状态不满足时跳过，并移除该项的待执行状态。
3. 将任务提交给有界线程池；同一主机或安卓实例使用单飞锁，避免并发重复请求。
4. 队列满、执行超时或目标不可用时丢弃本轮，记录采集失败或 `UNKNOWN`，不阻塞后续任务。
5. 成功结果写入指标快照；基础属性更新最新值，状态与字符指标保留最新值和变更记录。

定期清理任务根据系统配置 `metric_retention_days` 删除过期指标历史，默认 30 天。基础属性最新值不随历史清理删除。

## 阈值

阈值规则将“指标类型”改为“指标名称”，存储稳定的 `metric_code`。前端根据目录值类型提供条件：

- 数值：大于、小于、大于等于、小于等于、区间。
- 字符：等于、不等于、包含、不包含。
- 枚举：等于、不等于、属于集合、不属于集合；值从模板项 `enum_options` 多选。

未知、命令失败或解析失败的数值不会触发数值阈值。编辑规则时，持续时长字段必须使用后端保存值初始化，避免被默认值覆盖为 0 秒。

## 界面

新增指标模板管理区：

- 指标目录只读列表，展示目标类型、值类型、分类、单位、验证状态和建议频率。
- 模板列表与编辑页，选择兼容目录指标并设置默认频率、启用状态和枚举选项。
- 系统设置页配置指标历史保留天数。

设备详情页展示主机已应用模板、单项实际频率和最后采集时间。每张安卓实例卡片增加指标详情入口，展示继承配置、直接配置、最终生效项和频率，并支持管理实例覆盖。卡片基础信息使用已采集的 CPU 核心数、内存总量、设备型号和 Android 版本；非运行中实例显示“已暂停采集”。

## 接口与权限

- `GET /api/metric-catalogs`：目录查询。
- `/api/metric-templates`：模板及模板项管理。
- `/api/devices/{id}/metric-bindings`：主机模板与单项覆盖管理。
- `/api/devices/{id}/androids/{name}/metric-bindings`：安卓实例模板与单项覆盖管理。
- `/api/metrics/latest` 与 `/api/metrics/history`：指标查询。

登录用户可查看目录和设备指标；仅管理员可管理模板、绑定和系统配置。采集器只读模板、绑定和系统配置。原始 ADB Shell 接口仅由采集器调用受控目录命令，手动 Shell 操作继续遵循既有权限与审计要求。

## 验证

- 指标命令解析器、枚举选项、频率优先级和运行状态暂停/恢复的单元测试。
- 调度器到期执行、单飞、有界队列、超时与跳过策略测试。
- 模板、绑定、阈值、系统配置和迁移测试。
- 前端模板编辑、实例覆盖、类型化阈值条件和持续时长编辑回显测试。
- 在授权样本安卓实例执行目录中的只读命令，保存响应样本和验证结论；不得执行修改状态命令。

## 验收标准

- 不同主机与安卓实例可应用不同模板及多个指标项。
- 每个指标可按模板默认频率或设备覆盖频率独立采集。
- 非运行中目标不再产生相关采集请求。
- 枚举阈值只能选择已经验证并写入模板项的值。
- 设备详情可查看安卓实例的实际采集配置和基础属性。
- 持续时长规则编辑后保持保存的秒数。
- 调度器不会因多指标采集阻塞或无限堆积任务。
