# 指标目录与设备应用改造设计

## 目标

移除“指标模板”作为用户可见配置单元，改为一个统一的指标目录页面和设备级指标应用流程。指标目录提供默认配置；设备或安卓实例可应用并覆盖默认配置。阈值规则只能绑定可用指标，枚举指标可手动输入阈值，也可执行一次采集后选择返回值。

## 范围

本次改造覆盖：

- 指标目录、设备列表的单设备与批量应用、设备详情的指标展示。
- 指标模板和既有绑定记录的自动迁移。
- 阈值规则的指标来源和枚举值输入方式。

不改变：安卓实例状态的现有展示和采集逻辑；受控只读 ADB 命令白名单；告警恢复逻辑。

## 数据模型与迁移

### 指标目录

指标目录是唯一的默认配置来源。目录项按两级分类组织：

- 一级分类：`HOST`（主机）、`ANDROID_INSTANCE`（安卓实例）。
- 二级分类：指标分类，例如基础信息、性能、系统、内存、CPU、应用。

每个目录项至少包含指标编码、名称、值类型、单位、默认采集频率、是否支持阈值和排序信息。指标命令仍由 `MetricDefinitionRegistry` 固定定义，目录和设备配置均不能写入任意 Shell 或 ADB 命令。

### 设备应用

设备应用复用并演进 `metric_binding`，以 `device_id + android_name + metric_code` 为唯一业务维度：

- 主机指标的 `android_name` 为空。
- 安卓实例指标的 `android_name` 为具体实例名称。
- 应用记录保存启用状态、覆盖后的采集频率、必要的实例级参数和审计字段。
- `APP_PROCESS_STATE` 必须绑定具体安卓实例，并保存非空、合法的应用包名；快照、历史、阈值和告警继续按设备、实例、包名隔离。

### 模板迁移

在 Flyway 迁移中将既有模板绑定展开为设备应用记录：

1. 读取每个设备当前关联的模板及模板明细。
2. 为每个模板明细写入对应目标维度的 `metric_binding`；明细频率和枚举配置成为绑定覆盖值。
3. 同一设备、实例、指标发生冲突时，保留已有显式设备绑定；没有显式绑定时按既有模板绑定的确定顺序写入，并记录迁移日志。
4. 迁移后保留模板和模板明细表作为历史数据，但运行时新接口、页面和采集调度不再读取它们。

## 页面与交互

### 指标目录

菜单仅保留一个“指标目录”页面：

- 左侧树固定展示主机、安卓实例及其二级分类。
- 右侧表格展示该分类下的具体指标，并编辑默认采集频率、单位说明、阈值能力和排序等目录配置。
- 不再提供指标模板列表、创建、编辑或删除入口。

### 设备列表与单设备应用

设备列表每行提供“指标应用”操作，打开右侧抽屉：

- 选择主机或安卓实例；安卓实例模式先选该设备的具体实例。
- 按目录二级分类切换指标清单。
- 每个指标可启用或停用，并可覆盖默认采集频率。
- 对 `APP_PROCESS_STATE`，填写该实例对应的应用包名；未填写时不得保存该指标。

设备详情不再提供“指标绑定”页或入口。

### 批量应用

设备列表支持多选，并在有选中项时提供“批量应用指标”。使用分步抽屉：

1. 选择目标类型：主机或安卓实例。
2. 安卓实例模式中按主机分组，以复选框选择一个或多个安卓实例；每个选定设备可选择不同数量、不同名称的实例。无法获取实例的设备显示为跳过，不阻塞其他目标。
3. 按指标目录分类配置同一组指标：启用状态和采集频率；`APP_PROCESS_STATE` 为每个“设备 × 实例”单独填写应用包名。
4. 确认页按“设备 × 实例”展开实际应用目标和变更内容，再执行保存。

批量保存仅覆盖本次勾选的指标，不删除未勾选指标的既有应用。离线设备允许写入绑定配置，采集服务在设备恢复可用后按配置执行。

### 设备详情展示

指标展示由已应用指标与目录分类共同决定：

- 主机 / 系统分类的已应用指标显示在“基础信息”。
- 主机 / 基础、性能分类的已应用指标显示在“实时指标 / 主机指标”。
- 安卓实例分类的已应用指标显示在“实时指标 / 安卓实例指标”，并按选定实例隔离。
- 安卓实例状态维持现有页面和行为。

未应用的指标不显示为占位内容。

## 阈值规则

阈值规则的指标选择器不再使用维护在前端的固定列表，而是读取指标目录和实际设备应用：

- 只列出支持阈值的指标，并根据选择的作用范围过滤为至少存在一个已应用目标的指标。
- 数值指标沿用数值比较条件。
- 枚举指标提供“执行并获取选项”：以当前规则作用范围内选定的设备、安卓实例和应用包名立即采集一次，返回该隔离目标的枚举值供选择。
- 枚举阈值输入为可编辑的组合输入框：管理员既可从已获取选项中选择，也可手动输入任意非空合法文本。选择行为只是填充输入值，不限制手动输入。
- 阈值规则保存时保留目标范围、安卓实例和应用包名约束；枚举值的查询和比较不能跨设备、实例或包名混用。

## 接口边界

- 指标目录接口提供目录树、分类列表和目录项读写；废弃模板读写接口和前端调用。
- 设备指标应用接口支持单设备主机、单设备安卓实例以及批量目标写入；批量请求以明确的“设备 × 安卓实例”目标列表表达，服务端逐目标校验并返回逐目标结果。
- 阈值枚举选项接口接收规则当前的完整目标约束，并触发一次受控指标执行；不得接受任意命令内容。

## 异常处理

- 目录项、设备、安卓实例或指标编码不存在时返回明确业务错误，不创建部分无效配置。
- 批量操作对每个目标独立校验，返回成功、跳过与失败明细；仅校验失败的目标不写入，其余有效目标可保存。
- `APP_PROCESS_STATE` 缺少包名时，该目标为校验失败，不允许降级为未隔离的应用进程状态采集。
- “执行并获取选项”失败时保留当前手工输入，不覆盖未保存的阈值文本，并展示目标级失败原因。

## 验收与测试

- 迁移测试：既有模板和绑定被正确展开，显式设备绑定优先，迁移可重复执行。
- 服务测试：主机、实例、多个实例批量应用的覆盖和不删除语义；进程状态包名校验；批量结果明细。
- 阈值测试：仅显示已应用且支持阈值的指标；枚举选项按设备、实例、包名隔离；可选择也可手动输入枚举值。
- 前端测试：目录左右布局、设备行内抽屉、批量多实例选择、逐实例包名、确认页和详情页分类展示。
- 回归验证：采集调度、快照隔离、告警触发与自动恢复保持现有行为。
